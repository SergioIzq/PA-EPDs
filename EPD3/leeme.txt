EPD3 - Programación Avanzada: JavaScript básico (Ej1 a Ej6)
Equipo 04
----------------------------------------------------------------------------

ej1/  ej1.html + ej1.js            Informe estadístico de calificaciones
ej2/  ej2.html + ej2.js            Coste de envío de un paquete
ej3/  ej3.html + ej3.js            Formateo de códigos de actividad
ej4/  equipos, cuotas, intervalos  Tres páginas con snippets de CSS-Tricks (.html + .js)
ej5/  ej5.html + ej5.js            Gestor de actividades de un gimnasio
ej6/  ej6.html + ej6.js            Verificación de reservas a partir de un QR simulado

Abrir index.html (enlaza los seis ejercicios) o directamente el .html de cada uno. En Ej1, Ej2, Ej3, Ej5 y Ej6 la página lanza sola
el primer prompt y tiene un botón para repetirlo. El CSS va dentro de <style> en
cada HTML; no hay más archivos.

Ej1  Validación con reintento (entero > 0 para N, nota de 0 a 10, admite coma o
     punto). Media con Math.round, máximo y mínimo con Math.max/min, orden con
     sort((a, b) => a - b) y reverse().
Ej2  calcular() valida y devuelve el desglose, o { error } si hay un fallo.
     Errores: "DATOS INCORRECTOS" (peso o medidas) y "DESTINO INCORRECTO".
     El recargo del 15 % se aplica al subtotal con el suplemento internacional.
Ej3  Prioridad: múltiplo de 5 > múltiplo de 3 > par. La posición 0 solo cuenta
     como par. El carácter de los múltiplos de 5 se sustituye por "*" (ver
     SUSTITUTO en ej3.js).
Ej4  Cada página cita en su pie los snippets de https://css-tricks.com/snippets/javascript/
     que usa. Las técnicas se han reescrito y adaptado; no están copiadas tal cual.
       equipos.html     Remove Duplicates, Shuffle Array, Select Random Item,
                        Random Color, classList, Loop Over querySelectorAll
       cuotas.html      Format Currency, Comma Values in Numbers, Default Arguments,
                        Required Parameters, Get URL Variables, Loop Over querySelectorAll
       intervalos.html  setInterval con requestAnimationFrame, Intervals,
                        PageVisibility API, KeyboardEvent, Cookie Getter/Setter,
                        Different Stylesheet by Time of Day, Lighten/Darken Color
     La cookie de intervalos.html puede no guardarse si se abre el archivo
     directamente (file://) en algunos navegadores.
Ej5  Vector de 10 actividades (objetos { nombre, instructor, plazas }). Nombres
     comparados sin tildes ni mayúsculas. Errores: actividad inexistente, sin
     plazas, opción de menú no válida.
Ej6  Parámetros extraídos con URLSearchParams. Coste: 1.50 € base, +0.50 € si la
     duración es mayor de 30 min y -10 % si el identificador está entre 1 y 15.
     Con las reglas escritas, el ejemplo (spinning, 45, 15) da 1.80 €.
